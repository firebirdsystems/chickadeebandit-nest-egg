# Nest Egg

A [Chickadee Bandit](https://chickadeebandit.com/app-library/nest-egg) app.

Household financial overview — track net worth, savings goals, and named funds over time. Adults manage assets and liabilities; kids see their savings goals.

## Features

- Net worth from assets and liabilities.
- Named funds and savings goals with progress over time.
- Adults manage; kids see their own goals.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-nest-egg/releases/latest/download/bundle.json
```
